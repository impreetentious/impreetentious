**[Nexus IQ](https://github.com/ItsMonarch04/nexus-iq)** — A local-first workspace for turning qualitative text into calibrated measurement. Bring in surveys, documents or transcripts then build research instruments. Compare them with human-coded evidence before exporting reproducible reports.

<p align="center">
  <a href="https://github.com/ItsMonarch04/wind-tunnel">
    <img src="./assets/projects/wind-tunnel.svg?v=3" alt="Feature 02 / pricing — Wind Tunnel: test the price before the market does." width="100%" />
  </a>
</p>

**[Wind Tunnel](https://github.com/ItsMonarch04/wind-tunnel)** — A simulation workspace for pressure-testing SaaS pricing before launch. Model buyer segments plus willingness to pay then design tiers with feature fences or add-ons. See how customers self-select before a number reaches the pricing page.

<p align="center">
  <a href="https://github.com/ItsMonarch04/gt-sandbox">

</p>

**[Game Theory Sandbox](https://github.com/ItsMonarch04/gt-sandbox)** — An interactive way to learn game theory by playing first. Explore canonical games through repeated rounds then watch strategies compete across seeded tournaments or evolutionary simulations. Build custom payoff matrices with exact analytical feedback.
